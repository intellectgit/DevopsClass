Code Smell
Definition: A code smell is a maintainability issue. The code still works perfectly and won't crash your application, but it violates clean coding principles, is poorly structured, hard to read, 
and difficult to maintain or refactor in the future.

Code Bug
Definition: A bug is an error, flaw, or coding mistake that will cause the program to fail, behave incorrectly, or crash at runtime under certain conditions. It represents broken or unpredictable logic.

Real-Time Example: A NullPointerException risk (e.g., trying to read a variable property without checking if the object is null first), an unclosed database connection leak, or infinite loop potential.
